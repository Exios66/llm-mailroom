### Fixed

- **`/health` no longer blocks the event loop** on a slow LLM provider.
- **Postgres schema is created** by `ensure_schema` in `storage/db.py` (it previously never ran on the Postgres engine).
- **Relations:** explicit `0.0` edge scores were ignored in `record_edges`; concurrent writers could fork the relations ledger.
- **Audit log:** concurrent appends could fork the hash chain; writers now keep timestamps strictly monotonic.
- **`retry_extract_node` transient path no longer erases** the previous extraction.
- **Completeness judge** no longer emits an unguarded completeness score.
- **Routing:** a Lane B budget of `0` is honored (it was replaced by defaults).
- **LLM retry:** a capability `400` ("does not support feature") is not retried on the same model; non-object JSON no longer leaks out of `BaseAgent._call_structured`.
- **Arbiter:** a string `fields_to_fix` is no longer split into characters; null `reasoning` / `handoff_summary` no longer crash the node.
- **Sync-to-async bridges** no longer self-deadlock on a running event loop.
- **`POST /upload`:** path traversal and same-name overwrite are rejected.
